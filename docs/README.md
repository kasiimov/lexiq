переписке.

| [roadmap.md](roadmap.md) | Остальные разделы платформы: что сделано, что осталось |

## Решения, которые уже приняты

- **К экзамену не готовим.** Доводим до уровня, с которого IELTS становится
  посильным. Обещать балл, не проверяя человека вживую, нечестно — поэтому из
  приложения убран «прогноз band».
- **Сроков на обучение нет.** Блок закрывается результатом теста, а не
  календарём. Пропуск не наказывается.
- **Ключи ИИ живут только на сервере**, в edge-функциях. В браузер уходит
  один текст ответа.
- **Что можно сделать без сервера — делаем без сервера.** Задание дня
  одинаково у всех за счёт выбора по дате, а не за счёт общей базы.
- **Тариф будет платным.** Обещания «бесплатно навсегда» с сайта сняты,
  цена и лимиты — отдельная задача.

## Как писать сюда

Один файл — одна тема. Внутри: что делаем, почему именно так, и порядок
работ. Решения, от которых отказались, тоже оставляем с причиной — иначе
через месяц вернёмся к ним по кругу.
