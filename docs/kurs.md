# Основной курс — план

Главный раздел платформы. Сейчас у ученика есть отдельные тренажёры: слова,
чтение, письмо, чат. Их объединяет только уровень CEFR, а последовательности
нет — человек не знает, что делать сегодня и что будет завтра. Курс даёт эту
последовательность.

## Правило, от которого не отступаем

**Сроков нет.** Ни дедлайнов, ни «пройди за 30 дней», ни сгорающих уроков.
Блок закрывается тогда, когда ученик его сдал, — хоть через день, хоть через
полгода. Пропуск не наказывается: серия дней живёт отдельно и на курс не
влияет.

Ограничение только одно и оно смысловое: следующий блок открывается после
теста предыдущего. Не по времени, а по результату.

---

## Путь ученика

```
Выбор уровня  →  Проверочный тест  →  Курс уровня  →  Итоговый тест  →  Следующий уровень
   (сам)          (кроме Starter)     (блоки)         (закрывает уровень)
```

### 1. Выбор уровня

Шесть вариантов. Формулировки без терминов — человек, который не учил язык,
не знает, что такое A2:

| Что выбирает ученик | Уровень |
|---|---|
| Совсем не знаю английский | Starter |
| Знаю отдельные слова, читаю по слогам | A1 |
| Могу сказать простое предложение о себе | A2 |
| Понимаю обычную речь, говорю с ошибками | B1 |
| Свободно говорю на бытовые темы | B2 |
| Читаю статьи и книги без словаря | C1 |

### 2. Проверочный тест

**Starter теста не проходит** — сразу попадает на первый урок. Проверять
нечего, а тест на входе отпугивает именно тех, кому платформа нужнее всего.

Для остальных — 15 вопросов, три части по пять:

- **слова** — значение и употребление;
- **грамматика** — выбрать правильную форму;
- **чтение** — короткий абзац и вопросы по нему.

Считаем результат:

| Результат | Что делаем |
|---|---|
| 12–15 из 15 | уровень подтверждён, курс открывается |
| 8–11 | уровень подтверждён, но в первый блок добавляются повторительные уроки |
| меньше 8 | предлагаем уровень ниже — **предлагаем, а не заставляем**: ученик может настоять на своём |

Тест не наказывает. Его цель — не отсеять, а не дать человеку начать с
материала, где он утонет, и не заставить сильного проходить алфавит.

### 3. Курс уровня

Уровень состоит из **блоков** (bo'lim). Блок — это тема, которую можно
закрыть за несколько заходов:

```
Уровень A1
├── Блок 1. Знакомство и я сам
│   ├── Урок 1. Приветствия, местоимения I/you
│   ├── Урок 2. Глагол to be
│   ├── Урок 3. Мой возраст, город, семья
│   └── Тест блока  ← закрывает блок
├── Блок 2. Мой день
└── ...
```

**Урок** состоит из четырёх частей, всегда в одном порядке:

1. **Зачем** — одно предложение: что ученик сможет после урока.
2. **Правило** — объяснение по-узбекски, 3–5 пунктов, каждый с английским
   примером и переводом.
3. **Слова урока** — 6–10 штук с озвучкой, уезжают в общий словарь и потом
   возвращаются в повторение по Лейтнеру.
4. **Практика** — 5–8 упражнений: выбор варианта, пропуск в предложении,
   сборка предложения, перевод. Ошибся — сразу разбор, почему.

**Тест блока** — 10 вопросов по всем урокам блока. Порог 70%. Не сдал —
пересдача без ограничений, вопросы генерируются заново, поэтому зазубрить
ответы нельзя.

### 4. Итоговый тест уровня

20 вопросов по всем блокам плюс короткое письменное задание, которое
проверяется теми же критериями, что в разделе «Yozish». Сдал — следующий
уровень открыт, и это единственный способ его открыть.

## Как это устроено внутри

### Программа фиксирована, содержание генерируется

Список блоков и тем **записан в файле** `data/syllabus.json` — он не должен
меняться от запуска к запуску, иначе прогресс потеряет смысл: сегодня блок 3
про еду, завтра про погоду.

Содержание урока (правило, примеры, слова, упражнения) **генерирует ИИ** по
теме блока и уровню, а результат кэшируется. Так программа предсказуема, а
упражнения не кончаются и не повторяются.

```json
{
  "A1": [
    {
      "id": "a1-b1",
      "title": "Tanishuv va o'zim haqimda",
      "lessons": [
        { "id": "a1-b1-l1", "topic": "greetings, I / you, hello and goodbye" },
        { "id": "a1-b1-l2", "topic": "verb to be: am, is, are" },
        { "id": "a1-b1-l3", "topic": "age, city, family members" }
      ]
    }
  ]
}
```

### Что добавляется на сервере

Новый режим `course` у `/api/generate`: принимает `level`, `topic`, `kind`
(`lesson` | `practice` | `block_test` | `placement`) и возвращает готовую
структуру. Отдельная функция не нужна — цепочка провайдеров, повторы при
перегрузке и проверка JSON уже написаны и работают.

### Что хранится

| Ключ | Что |
|---|---|
| `lexiq_course` | выбранный уровень, результат входного теста, открытые блоки |
| `lexiq_progress` | по каждому уроку: пройден, дата, результат теста блока |
| `lexiq_lesson_cache` | сгенерированные уроки, чтобы не ждать ИИ второй раз |

Всё то же уезжает в Firestore под аккаунтом — как уже сделано для словаря и
серии.

### Экраны

1. `s-onboard` — выбор уровня, шесть карточек.
2. `s-placement` — проверочный тест, 15 вопросов, три части.
3. `s-course` — карта курса: блоки и уроки, видно открытое и закрытое.
4. `s-lesson` — урок: правило, слова, практика.
5. `s-blocktest` — тест блока и его результат.

Главный экран меняется: сверху появляется **«Продолжить урок»** — самая
крупная кнопка, ведёт ровно туда, где ученик остановился. Тренажёры (слова,
чтение, письмо, чат) остаются, но становятся дополнением к курсу, а не
единственным содержанием.

## Порядок работы

1. `data/syllabus.json` — программа A1–C1, по 5–7 блоков на уровень. 🟡
2. Выбор уровня и проверочный тест. 🟡
3. Карта курса и экран урока. 🔴
4. Тесты блоков, пороги, пересдачи. 🟡
5. Итоговый тест уровня. 🟡
6. Перенос прогресса курса в аккаунт. 🟢
7. Главная перестраивается вокруг «Продолжить урок». 🟢

Starter, A1 и A2 делаем первыми и полностью: на них придётся большинство
учеников. B1–C1 добавляем той же механикой, когда нижние уровни обкатаны.
